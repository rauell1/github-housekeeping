Choose How You Want to Use GitHub Follow Housekeeping

This tool works both as an instant browser web app (hosted on Cloudflare) and as a local CLI tool.

🌐 Web App Mode (Cloudflare) Current Mode

Zero installation. Runs 100% inside your browser and talks directly to api.github.com.

  • Public Audit (No Token): Type any @username above to view public non-followers, mutuals, and fans.
  • Full Housekeeping (1-Click Token Generator): Click Get Token & Sign In to open GitHub with the user:follow permission pre-selected, then paste the token to unlock unfollowing for your own account.
  • Allowlist Storage: Saved in your browser's localStorage (with JSON export/import).
💻 Local CLI Mode (npx / gh CLI) Current Mode

Best for developers who already have the official GitHub CLI (gh) installed locally.

  • Run Locally: npx github:rauell1/github-housekeeping --open
  • Zero PAT Setup: Automatically reuses your local gh auth login. Run gh auth refresh -h github.com -s user:follow to enable 1-click unfollow.
  • Allowlist Storage: Persisted directly to disk (~/.github-housekeeping/allowlist.json).
🛡 Ownership & GitHub Rules Compliance: Anyone's followers/following lists are public on GitHub, so public scanning is read-only. However, unfollowing is strictly locked to the verified token owner's account, so you can never modify another user's account. Unfollow requests are paced serially (300ms apart) to respect GitHub rate limits.
Read-Only Mode You can scan any account and curate your allowlist. To enable 1-click unfollowing for your account, connect a token with the user:follow permission.

✨ Create a Token in 3 Easy Clicks (No Technical Setup Needed)

To verify that you own your GitHub account, GitHub uses a temporary access code called a Personal Access Token.

  1. Choose the permission level you need. It opens GitHub with the boxes already ticked for you:
    Follow Housekeeping Only (user:follow) ↗ Follow + Repo Deletion (user:follow, delete_repo, repo) ↗
  2. Scroll to the bottom of that GitHub page, click the green "Generate token" button, and copy the code starting with ghp_.
  3. Paste that code in the box below and click Save & Verify Token.

Paste Your GitHub Token

Kept strictly in your browser's temporary session memory and never stored on any external server.

Alternative (For Terminal / CLI Users): GitHub CLI (gh)

When running locally via npx, grant user:follow (and optionally delete_repo) to your local gh session:

gh auth refresh -h github.com -s user:follow,delete_repo

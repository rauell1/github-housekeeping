Choose How You Want to Use GitHub Follow Housekeeping

This tool works both as an instant browser web app (hosted on Cloudflare) and as a local CLI tool.

🌐 Web App Mode (Cloudflare) Current Mode

Zero installation. Runs 100% inside your browser and talks directly to api.github.com.

  • Public Audit (No Token): Type any @username above to check non-followers, mutuals, and fans.
  • Full Housekeeping (Browser Token): Click Auth Settings to paste a token with user:follow scope. Kept in your browser session only—never sent to any backend server.
  • Allowlist Storage: Saved in your browser's localStorage (with JSON export/import).
💻 Local CLI Mode (npx / gh CLI) Current Mode

Best for developers who already have the official GitHub CLI (gh) installed locally.

  • Run Locally: npx github-housekeeping --open
  • Zero PAT Setup: Automatically reuses your local gh auth login. Run gh auth refresh -h github.com -s user:follow to enable 1-click unfollow.
  • Allowlist Storage: Persisted directly to disk (~/.github-housekeeping/allowlist.json).
🛡 GitHub Rules & Rate-Limit Compliance: This tool only performs manual, user-confirmed housekeeping using official GitHub REST & GraphQL APIs. It never auto-follows or performs follow-churn automation, and serializes unfollow requests with a 300ms delay to respect GitHub's secondary rate limits.
Read-Only Mode You can scan any account and curate your allowlist. To enable 1-click unfollowing, grant the user:follow scope.
